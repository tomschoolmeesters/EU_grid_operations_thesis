# EU_grid_operations_thesis.jl Documentation

## Overview

`EU_grid_operations.jl` is a Julia package designed to model, simulate, and solve a variety of planning and operational Optimal Power Flow (OPF) problems on the European transmission grid. It provides tools for analyzing grid behavior under different scenarios, supporting both steady-state and investment-focused studies.

As part of ongoing academic research, the package has been extended to support Transmission Network Expansion Planning (TNEP) applications. In particular, it has been adapted for use in the context of the North Sea grid, where it enables filtering of relevant candidate transmission lines and optimizes their inclusion in future grid configurations. This enhanced functionality supports advanced scenario analysis and strategic decision-making for offshore and cross-border energy infrastructure.
